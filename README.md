# Student Performance Analysis

Analysis of the Students Performance in Exams dataset (1,000 students):
data exploration, five factor questions, six charts, at-risk segmentation
and a Principal's Report with recommendations.

## Files
- `student-performance-analysis.ipynb` - full analysis notebook

## Tools
Python, pandas, matplotlib, seaborn (Kaggle notebook)

## Key findings
- Parental education: average score rises from 63.1 to 73.6 across levels
- Test prep: completers average 72.7 vs 65.0 for non-completers
- Reading and writing are almost perfectly correlated (0.95)
- 188 students (18.8%) are at-risk (below 50 in any subject)
- Highest at-risk groups: free/reduced lunch (31.3%), no test prep (23.7%)

## How to run
Open the notebook on Kaggle with the dataset attached and run all cells.
